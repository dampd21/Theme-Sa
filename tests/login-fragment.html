처음 연결하나요? 토큰 준비하기
  1. 관리자에게 비공개 저장소 초대를 받고 수락해요.
  2. GitHub 설정 → Developer settings → Personal access tokens → Fine-grained tokens로 이동해요.
  3. 소유자를 선택하고, Only select repositories에서 기록 저장소 하나만 선택해요.
  4. Repository permissions의 Contents: Read and write를 설정해요. 만료 기간은 짧게 설정하세요. Metadata 읽기 권한은 자동 포함돼요.
  5. 발급된 내 토큰을 위에 입력해요. 읽기 전용 토큰으로는 열람만 가능해요.
