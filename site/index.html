백업 파일 불러오기는 팀 전체 기록을 바꿔요. 백업 파일에도 개인정보가 있으니 공개하지 마세요. GitHub는 삭제한 내용도 커밋 이력에 남기므로 상세 집주소는 기록하지 마세요.

A LITTLE FIELD GUIDE

기록실 사용 안내

우리만의 팀을 만드는 네 가지 방법.

01

권한이 있는 친구만 입장해요

관리자 본인의 GitHub 개인 접근 토큰으로 비공개 기록 저장소에 연결합니다. 전용 Fine-grained 토큰을 권장하고 Classic 토큰도 지원합니다. 공용 비밀번호 방식이 아니며 토큰은 공유하지 마세요.

02

수정한 뒤 GitHub에 저장해요

팀명 변경, 팀원 추가·수정·삭제, 팀장 변경은 모두 비공개 저장소의 같은 JSON 파일에 저장돼요. 성공 알림을 확인해야 저장이 완료된 거예요. 단순히 입력만 한 내용은 저장되지 않아요.

03

함께 편집해도 덮어쓰지 않아요

평소에는 30초마다 최신 기록을 확인해요. 창을 편집 중이면 자동 반영을 잠시 멈춰요. 친구가 먼저 저장했다면 충돌을 알리고 덮어쓰지 않아요. 내 변경을 파일로 보관하고 최신 기록을 불러온 다음 필요한 부분만 다시 적용해 주세요.

04

사용한 뒤 로그아웃해요

토큰과 팀 기록은 이 페이지의 메모리에만 있어요. 새로고침하면 다시 로그인해요. 우측 상단 자물쇠로 로그아웃하면 화면과 메모리의 기록을 비워요. 브라우저의 GitHub 로그인은 별도이므로 공용 기기에서는 GitHub에서도 로그아웃하세요.

팀원 정보는 GitHub로 전송되며 저장소 커밋 이력에도 남아요. 친구에게 동의를 받고, 실제 상세 주소 대신 가상 설정이나 별칭을 사용하세요. 이 사이트는 공통 비밀번호나 Actions Secrets를 로그인 수단으로 사용하지 않아요.
